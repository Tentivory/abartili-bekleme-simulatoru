# Abartılı Bekleme Simülatörü

## Giriş (Ciddi Gibi Görünen Ama Değil)

Bu repository, modern insanlığın en büyük sorununu çözmek için yaratılmıştır: **Beklemek**.

Evet, beklemek. Trafikte beklemek, çay demlenmesini beklemek, cevap beklemeyi beklemek, hatta beklemenin bitmesini beklemek. Bu simülatör, tüm bu varoluşsal acıyı komik mesajlarla süsleyerek size sunar. Kod gerçekten çalışır. Gerçekten bekletir. Gerçekten güler.

### Nasıl Çalışır?

1. Python 3 ile `python bekleme.py` çalıştırın.
2. Bekleyin. (Zaten o yüzden buradasınız.)
3. Mesajları okuyun, gülün, tekrar bekleyin.
4. Çıkmak için Ctrl+C (ama çıkmak da bir bekleme değil mi?).

### Özellikler (Abartılı)

- Rastgele Türkçe bekleme mesajları
- Yavaşlayan progress bar (bazen geri gider)
- Asla bitmeyen bir şey hissi
- Felsefi derinlik (yok aslında)
- Kahve molası tavsiyeleri (kahve yok ama tavsiye var)

### Uyarı

Bu kodu çalıştırmak ömrünüzden gün alabilir. Sorumluluk kabul etmiyoruz. Beklemek size kalmış.
